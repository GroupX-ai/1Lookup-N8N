# Changelog

All notable changes to this project will be documented in this file.

## 1.0.1

- Removed the `X-API-KEY` credential header so the node matches direct API authentication behavior.
- Added Email Enrichment, Mobile Finder, HLR Lookup, MNP Lookup, Number Type Lookup, and Search Intent Lookup operations.
- Updated package homepage and README links to `https://1lookup.io`.

## 1.0.0

- Initial public package scaffold for the 1Lookup n8n community node.
- Added 1Lookup API credentials and core email, phone, IP, and domain operations.
- Added release workflow for npm publishing with provenance support.
